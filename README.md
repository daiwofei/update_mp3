# 华明新能源 · 智能语音调度台（第一阶段）

面向 4G 物联网终端的语音素材准备与播放计划编排原型。本阶段实现：

- 四级地图索引：中国设备地图 → 武汉市地图 → 九万里人才基地 3D 楼宇 → 具体设备工作台。
- MP3 语音素材库：默认素材、MP3 上传、分类筛选、搜索、试听与 TTS 文案预览。
- 播放计划编排：从素材库加入计划、拖拽排序、置顶、定时、保存草稿和发布。

当前版本是无后端依赖的前端原型，数据保存在浏览器 `localStorage`，上传文件在当前页面会话中可试听。科大讯飞 TTS 和真实设备同步将在后续阶段接入。

地图页面使用天地图 JavaScript API 4.0，提供中文地名、道路、水系、缩放、比例尺和图层切换。首次使用时可在页面中填写天地图浏览器端 Token，也可以在 `tianditu-map-config.js` 中由部署系统注入。武汉标记采用 WGS 84 坐标 `30.5928, 114.3055`；九万里人才基地当前使用武昌区演示坐标 `30.5440, 114.3160`，上线前应替换为现场准确坐标。

## 本地运行

现在可以直接打开 `index.html` 并尝试载入天地图。为了获得稳定的来源地址、浏览器存储和网络错误提示，开发调试仍推荐在项目目录中运行：

```bash
python3 -m http.server 4173
```

浏览器打开 <http://localhost:4173>。

## 配置天地图

1. 在天地图开发者平台申请浏览器端 Token。
2. 确认 Token 已启用，并按控制台要求配置当前网站域名。
3. 可直接打开 `index.html`；如果 Token 的域名策略不接受 `file://`，改用 `http://localhost:4173`。
4. 在网页的地图配置窗口填写 Token，或者配置 `tianditu-map-config.js`。
5. 如果地图没有载入，请检查 Token 状态、域名限制、调用配额和网络连接。

网页不会再因为 `file://` 主动阻止地图加载。地图无法显示时，页面会直接呈现脚本超时、Token 缺失或网络失败等具体错误；浏览器控制台还会保留完整异常。

## 项目结构

