# 华明新能源 · 智能语音调度台（第一阶段）

面向 4G 物联网终端的语音素材准备与播放计划编排原型。本阶段实现：

- 四级地图索引：中国设备地图 → 武汉市地图 → 九万里人才基地 3D 楼宇 → 具体设备工作台。
- MP3 语音素材库：默认素材、MP3 上传、分类筛选、搜索、试听与 TTS 文案预览。
- 播放计划编排：从素材库加入计划、拖拽排序、置顶、定时、保存草稿和发布。

当前版本是无后端依赖的前端原型，数据保存在浏览器 `localStorage`，上传文件在当前页面会话中可试听。科大讯飞 TTS 和真实设备同步将在后续阶段接入。

地图页面使用百度地图 WebGL JS API，提供中文地名、道路、水系、缩放、比例尺、普通/卫星图层切换和城市级 3D 视角。首次使用时可在页面中填写百度地图浏览器端 AK，也可以在 `baidu-map-config.js` 中由部署系统注入。武汉标记采用百度 BD-09 演示坐标 `30.5980, 114.3120`；九万里人才基地当前使用武昌区演示坐标 `30.5500, 114.3225`，上线前应替换为现场准确的 BD-09 坐标。

## 本地运行

```bash
python3 -m http.server 4173
```

浏览器打开 <http://localhost:4173>。
