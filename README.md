# 华明新能源 · 智能语音调度台（第一阶段）

面向 4G 物联网终端的语音素材准备与播放计划编排原型。本阶段实现：

- 四级地图索引：中国设备地图 → 武汉市地图 → 九万里人才基地 3D 楼宇 → 具体设备工作台。
- MP3 语音素材库：默认素材、MP3 上传、分类筛选、搜索、试听与 TTS 文案预览。
- 播放计划编排：从素材库加入计划、拖拽排序、置顶、定时、保存草稿和发布。

当前版本是无后端依赖的前端原型，数据保存在浏览器 `localStorage`，上传文件在当前页面会话中可试听。科大讯飞 TTS 和真实设备同步将在后续阶段接入。

地图页面采用完全离线的内嵌 SVG 静态方案，不需要百度、高德、天地图 Token、第三方脚本或在线瓦片。全国层级包含中国轮廓、省区标签、经纬网和武汉设备坐标；武汉层级包含长江、汉江、城区、道路、桥梁和九万里人才基地坐标。武汉标记采用 WGS 84 坐标 `30.5928, 114.3055`；九万里人才基地当前使用武昌区演示坐标 `30.5440, 114.3160`，上线前应替换为现场准确坐标。

## 本地运行

静态地图不需要网络，可以直接打开 `index.html`。为了获得稳定的浏览器存储和 MP3 文件访问，开发调试仍推荐在项目目录中运行：

```bash
python3 -m http.server 4173
```

浏览器打开 <http://localhost:4173>。

## 静态地图说明

- 两级地图全部内嵌在 `index.html`，断网也能正常显示和点击。
- 地图用于设备和项目的可视化索引，不承担导航、测距或测绘用途。
- 当前城市道路及项目坐标为产品原型数据，正式上线前需要替换为现场确认的数据。
- 对外公开发布前，应使用具有审图号的标准地图素材复核中国轮廓、边界和标注。
